================================================================================
ATTENDANCE SYSTEM WITH FINGERPRINT - TECHNOLOGY STACK AND FOLDER STRUCTURE
================================================================================

PROJECT OVERVIEW:
This is a comprehensive Attendance Management System with Fingerprint Integration.
It consists of a modern React frontend and a Python FastAPI backend with database 
integration for managing employee attendance, salaries, and user accounts.

================================================================================
FRONTEND TECHNOLOGY STACK
================================================================================

Language & Framework:
  - React 18.2.0 - UI library for building user interfaces
  - TypeScript 5.3.3 - Type-safe JavaScript superset
  - Vite 5.0.12 - Fast build tool and development server

Styling & UI:
  - Tailwind CSS 3.4.1 - Utility-first CSS framework
  - PostCSS 8.4.33 - CSS transformation tool
  - Autoprefixer 10.4.17 - Vendor prefix automation
  - Lucide React - Icon library

Routing & Navigation:
  - React Router DOM 6.21.3 - Client-side routing

HTTP & API Communication:
  - Axios 1.6.5 - Promise-based HTTP client

Utilities & Helpers:
  - date-fns 3.3.1 - Date formatting and manipulation
  - react-hot-toast 2.4.1 - Toast notifications

Development Tools:
  - ESLint 8.56.0 - Code quality and linting
  - @types packages - TypeScript definitions for libraries

================================================================================
DEVELOPMENT SETUP
================================================================================

Frontend Setup:
  1. Navigate to frontend directory: cd frontend
  2. Install dependencies: npm install
  3. Create .env file with API endpoint configuration
  4. Start dev server: npm run dev

Backend Setup:
  1. Navigate to backend directory: cd backend
  2. Create virtual environment: python -m venv venv
  3. Activate virtual environment: source venv/bin/activate (Linux/Mac)
  4. Install dependencies: pip install -r requirements.txt
  5. Run migrations: python migrate_database.py
  6. Start server: python app_launcher.py
