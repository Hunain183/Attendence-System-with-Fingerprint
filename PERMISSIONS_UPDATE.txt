1. Role Check Function:
   ```typescript
   const isPrimaryAdmin = () => {
     const token = localStorage.getItem('token');
     if (!token) return false;
     try {
       const payload = JSON.parse(atob(token.split('.')[1]));
       return payload.role === 'primary_admin';
     } catch {
       return false;
     }
   };
   ```

                        SECURITY CONSIDERATIONS
======================================================================================

1. BACKEND VALIDATION:
   - All endpoints check user role via JWT token
   - require_roles() dependency validates permissions
   - Returns 403 Forbidden if role not authorized
   - Token validation happens before endpoint execution

2. FRONTEND UI CONTROL:
   - Delete buttons hidden for secondary admin
   - Prevents accidental attempts to delete
   - Server-side validation still enforces restrictions
   - UI reflects actual backend permissions

3. DEFENSE IN DEPTH:
   - Frontend hides UI elements (user experience)
   - Backend enforces permissions (security)
   - Even if frontend bypassed, backend rejects unauthorized requests
   - JWT token contains role, cannot be tampered with

======================================================================================
                        BUSINESS JUSTIFICATION
======================================================================================

WHY RESTRICT EMPLOYEE DELETION?
  - Employees have related records (attendance, salaries)
  - Deletion is permanent and cannot be undone
  - Deletes cascade to attendance records
  - Should require highest authorization level
  - Prevents accidental data loss
  - Maintains data integrity

WHY ALLOW ATTENDANCE UPDATES?
  - Corrections needed for genuine mistakes
  - Device failures require manual updates
  - Time adjustments for legitimate reasons
  - Part of daily administrative tasks
  - Does not permanently delete data
  - Can be audited and tracked

WHY RESTRICT ATTENDANCE DELETION?
  - Attendance records needed for payroll
  - Historical data for compliance
  - Audit trail requirements
  - Should only be removed by senior admin
  - Prevents manipulation of attendance data
