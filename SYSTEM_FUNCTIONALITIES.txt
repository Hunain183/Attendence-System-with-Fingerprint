  * Net Salary (auto-calculated)
  
4.2 SALARY CALCULATION
----------------------
Formula:
  Base Salary = (Basic Salary / Working Days) × Present Days
  Overtime Pay = Overtime Hours × Hourly Rate
  Gross Salary = Base Salary + Overtime Pay + Bonuses
  Net Salary = Gross Salary - Deductions

4.3 SALARY STATUS TRACKING
--------------------------
Three status levels:
  - PENDING: Salary created but not approved
  - APPROVED: Verified by admin, ready for payment
  - PAID: Payment completed and recorded

15.3 API ENDPOINTS
------------------
Authentication:
  POST /auth/register - Register new user
  POST /auth/login - Login user
  POST /auth/logout - Logout user

Users:
  GET /users - List all users
  POST /users - Create user
  GET /users/{id} - Get user details
  PUT /users/{id} - Update user
  DELETE /users/{id} - Delete user

Employees:
  GET /employees - List all employees
  POST /employees - Create employee
  GET /employees/{id} - Get employee details
  PUT /employees/{id} - Update employee
  DELETE /employees/{id} - Delete employee
  POST /employees/{id}/fingerprint - Enroll fingerprint

Attendance:
  GET /attendance - List attendance records
  POST /attendance/clock-in - Clock in (device)
  POST /attendance/clock-out - Clock out (device)
  POST /attendance/manual - Manual attendance entry
  GET /attendance/report - Generate reports

Salaries:
  GET /salaries - List all salaries
  POST /salaries - Create salary record
  GET /salaries/{id} - Get salary details
  PUT /salaries/{id} - Update salary
  DELETE /salaries/{id} - Delete salary
  PUT /salaries/{id}/approve - Approve salary
  PUT /salaries/{id}/pay - Mark as paid

================================================================================
                        KEY WORKFLOWS
================================================================================

16.1 NEW EMPLOYEE ONBOARDING
----------------------------
1. Admin logs into system
2. Navigate to Employees page
3. Click "Add Employee" button
4. Fill employee form (6 sections):
   - Basic Information (name, CNIC, contact, etc.)
   - Address Details
   - Employment Details (department, designation, HOD, etc.)
   - Salary Information (monthly salary, rate per day)
   - Reference Information (2 references)
   - Previous Employment details
5. Click "Save Employee"
6. Click "Enroll Fingerprint" on employee row
7. Scan employee fingerprint using device
8. Confirm and save fingerprint template
9. Employee can now use kiosk for attendance

16.2 DAILY ATTENDANCE MARKING
-----------------------------
OPTION 1: Fingerprint (Kiosk Mode)
1. Employee goes to kiosk station
2. Places finger on scanner
3. System identifies employee
4. Displays welcome message
5. Records clock in/out time
6. Shows confirmation

OPTION 2: Manual Entry (Admin)
1. Admin navigates to Manual Attendance
2. Selects employee from dropdown
3. Selects date
4. Enters clock in time
5. Enters clock out time
6. Provides reason for manual entry
7. Saves attendance record

16.3 MONTHLY SALARY PROCESSING
------------------------------
1. Admin navigates to Salary page
2. Clicks "Add Salary" button
3. Selects employee
4. Selects month and year
5. System auto-fills:
   - Basic salary (from employee record)
   - Present days (from attendance)
   - Absent days (calculated)
   - Overtime hours (from attendance)
6. Admin enters:
   - Bonuses (if any)
   - Deductions (if any)
7. System calculates net salary
8. Saves salary record with status "Pending"
9. Primary admin reviews and approves
10. Status changes to "Approved"
11. After payment, mark as "Paid"

16.4 GENERATING REPORTS
-----------------------
1. Admin navigates to Reports page
2. Selects desired tab:
   - Attendance Reports
   - Salary Reports
   - Employee Reports
3. Applies filters:
   - Date range
   - Department
   - Employee
   - Status
4. Views results in table
5. Options:
   - Print report
   - Export to Excel
   - Export to CSV
6. Click Print for formatted output
