======================================================================================
                        TROUBLESHOOTING
======================================================================================

ISSUE: BUILD_EXE.bat fails
FIX: 
  1. Run STOP_App.bat first
  2. Check Python version (3.11 or 3.12)
  3. Delete backend/build and backend/dist folders
  4. Try again

ISSUE: Frontend build fails
FIX:
  1. cd frontend
  2. npm install
  3. npm run build
  4. Check for TypeScript errors

ISSUE: Executable won't run
FIX:
  1. Check Windows version (10/11 required)
  2. Run as Administrator
  3. Check antivirus (may block)
  4. Ensure port 8000 is free

ISSUE: Database errors
FIX:
  1. Delete attendance.db
  2. Run migrate_database.py
  3. Restart application

ISSUE: Permission errors
FIX:
  1. Check token in browser DevTools
  2. Verify role in JWT payload
  3. Re-login to refresh token
